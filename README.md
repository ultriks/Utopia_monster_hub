# Utopia Monster Hub

Welcome to the Utopia Monster Hub(UMH from now on). UMH is an app created by me to have a place where you can create, edit and manage creatures you can create using the custom ruleset from [Utopia ttrpg](https://myramyth.com/utopia). This is more for people who play offline but do not want to open like 20 browser tabs to get the statblocks for creatures and stuff

## Why does it exist?
I know there are google sheets made by the amazing discord community of Utopia, but I found it really annoying to have multiple tabs open to manage all the creatures in my combats. Also I, for the life of me couldn't find a good initiative tracker for Utopia, since it's not that popular, sadly.

## What the project already has implemented

- All the kits from the erraa in the book are implemented
- All the classes are also here(items still need adding to them)
- The ability to create, duplicate and edit creatures
